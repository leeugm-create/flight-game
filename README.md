**Coral Skylark** — an original WebGL flight game that runs entirely from static files in a desktop browser, no network requests. Fly a coral-and-cream tourer over a procedural island coastline: chase and cockpit views, a six-gauge lit instrument panel, a glowing 10-ring course to thread, a marked runway for a landing bonus, fuel burn, hull damage and a five-minute sortie timer. Keyboard and mouse controls; altitude, speed and heading on the HUD throughout.

## Run it

```sh
python3 -m http.server -d game 8000
# then open http://localhost:8000 in a desktop browser
```
